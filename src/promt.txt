## 3. Detailed 3D & Scroll Behavior Mechanics (Vanilla JS + GSAP)
This is the core requirement. Implement the interactive effects using Vanilla JavaScript and GSAP ScrollTrigger:
* **Interactive 3D Canvas Background:** 
  - Set up a full-screen Three.js WebGL renderer sitting behind the HTML content (`z-index: -1` or fixed position).

  - Listen to `mousemove` events across the window. Smoothly tilt, rotate, or shift the 3D objects or camera slightly based on normalized cursor coordinates (`clientX`, `clientY`) using linear interpolation (lerp) for buttery-smooth damping.
* **Scroll-Driven 3D Choreography:**

  - As the user scrolls down through different page sections, animate the Three.js camera position (`camera.position.x/y/z`), rotation, or object scale so the 3D scene evolves dynamically with every section transition (e.g., Hero -> About -> Projects -> Contact).
* **Performance & Responsiveness:**
  - Handle window `resize` events correctly to update Three.js aspect ratio and renderer size.
  - Cap the device pixel ratio (`renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2))`) for mobile performance.
