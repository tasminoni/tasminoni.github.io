Projects and experience in full-stack web development, backend services, and software engineering.

## Local development

```sh
npm ci
npm run dev
```

The `main` branch deploys to GitHub Pages through `.github/workflows/deploy.yml`.

## Google Search setup

After deploying, add `https://tasminoni.github.io/` as a URL-prefix property in [Google Search Console](https://search.google.com/search-console/). Verify ownership, submit `https://tasminoni.github.io/sitemap.xml`, and use URL Inspection to request indexing for the homepage. Check the Page indexing and Performance reports to see whether Google has indexed the page and which searches show it.
